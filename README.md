### Hi, I'm Ondrej.

I'm an audiology technician, gym owner and developer from Czechia. I build my own projects with Codex and other AI tools.

- [Dots Brain](https://github.com/OnFiala/Dots-Brain): a memory service for notes you explicitly save through MCP. You can try it on Linux, but it's still a work in progress.
- [Auralis](https://github.com/OnFiala/auralis-webmcp): compare a family conversation under different illustrative listening conditions, on your own or with an agent through WebMCP. An educational, non-clinical demo.
- [8 Instructions](https://github.com/OnFiala/eight-instructions): one coding agent building a computing environment in Brainfuck, a language with eight commands.
- [iHear](https://github.com/OnFiala/iHear): a demo for recording everyday listening difficulties before a hearing-care appointment. Publicly visible proprietary source; no public app yet.
- [ofops-skills](https://github.com/OnFiala/ofops-skills): skills I use with coding agents for refactoring, delegation, migrations and checking what actually works.
